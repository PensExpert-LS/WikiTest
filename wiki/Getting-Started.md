# Getting Started

Herzlich willkommen! Diese Anleitung hilft Ihnen, sich mit unserer Wissensdatenbank vertraut zu machen.

## Was ist diese Wissensdatenbank?

Diese GitHub Wiki dient als zentrale Wissensdatenbank für unser Unternehmen - ähnlich wie Confluence, aber direkt in GitHub integriert.

## Vorteile von GitHub Wiki

✅ **Versionskontrolle** - Alle Änderungen werden nachverfolgt  
✅ **Markdown-basiert** - Einfache Formatierung  
✅ **Zusammenarbeit** - Jeder kann beitragen  
✅ **Suchfunktion** - Schnelles Finden von Informationen  
✅ **Integration** - Direkt mit Code-Repository verbunden  

## Erste Schritte

### 1. Navigation

Nutzen Sie die **Sidebar** (links) für die Hauptnavigation zwischen Seiten.

### 2. Seiten lesen

Klicken Sie auf Links, um zu verschiedenen Themenbereichen zu navigieren.

### 3. Seiten bearbeiten

- Klicken Sie auf **"Edit"** oben rechts auf jeder Seite
- Nehmen Sie Ihre Änderungen in Markdown vor
- Fügen Sie eine beschreibende Commit-Nachricht hinzu
- Klicken Sie auf **"Save Page"**

### 4. Neue Seiten erstellen

- Klicken Sie auf **"New Page"**
- Geben Sie einen aussagekräftigen Titel ein
- Schreiben Sie Ihren Inhalt in Markdown
- Speichern Sie die Seite
