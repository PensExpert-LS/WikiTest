# Willkommen zur Unternehmens-Wissensdatenbank

Willkommen in unserer zentralen Wissensdatenbank! Diese Wiki dient als zentrale Anlaufstelle für alle Informationen rund um unser Unternehmen, ähnlich wie Confluence.

## 📚 Hauptbereiche

### [Onboarding](Onboarding)
Alle Informationen für neue Mitarbeiter
- Erste Schritte
- Accounts und Zugänge
- Team-Vorstellungen

### [Entwicklungsrichtlinien](Development-Guidelines)
Best Practices und Standards für die Entwicklung
- Coding Standards
- Git Workflow
- Code Review Prozess

### [Unternehmensprozesse](Company-Processes)
Dokumentation aller wichtigen Prozesse
- Urlaubsantrag
- Zeiterfassung
- Genehmigungsprozesse

### [FAQ](FAQ)
Häufig gestellte Fragen und Antworten

## 🚀 Schnellstart

Neu hier? Beginnen Sie mit unserem [Getting Started Guide](Getting-Started).

## 📝 Wie Sie beitragen können

1. Klicken Sie auf "Edit" auf jeder Wiki-Seite
2. Nehmen Sie Ihre Änderungen vor
3. Fügen Sie eine aussagekräftige Commit-Nachricht hinzu
4. Speichern Sie die Änderungen

## 🔍 Suche

Nutzen Sie die Suchfunktion oben rechts, um spezifische Informationen zu finden.

## 📞 Kontakt
