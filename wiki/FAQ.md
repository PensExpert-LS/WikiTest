## 👨‍💻 Entwicklung

### Git & GitHub

**Q: Welche Branch-Strategie verwenden wir?**  
A: Siehe [Git Workflow](Git-Workflow) für Details. Kurz: Feature-Branches von `develop`, dann Pull Request.

**Q: Wie schreibe ich gute Commit-Messages?**  
A: Format: `type(scope): Kurzbeschreibung`. Details im [Git Workflow](Git-Workflow).

**Q: Kann ich direkt auf `main` pushen?**  
A: Nein! `main` ist geschützt. Immer über Pull Requests.

**Q: Wie groß sollte ein Pull Request sein?**  
A: Idealerweise 200-400 Zeilen. Größere PRs in kleinere aufteilen.

### Code Review

**Q: Wie lange dauern Code Reviews?**  
A: Kleine PRs innerhalb 1 Tag, mittlere innerhalb 2 Tagen.

**Q: Wer sollte mein Code reviewen?**  
A: Mindestens ein Teammitglied, idealerweise jemand mit Kontext zum betroffenen Code.

**Q: Wie reagiere ich auf Review-Kommentare?**  
A: Konstruktiv diskutieren, Änderungen einarbeiten, als "Resolved" markieren.

### Testing

**Q: Muss ich Tests schreiben?**  
A: Ja! Siehe [Development Guidelines](Development-Guidelines) für Testing-Best-Practices.

**Q: Welche Test-Coverage ist erwünscht?**  
A: Mindestens 80% für neuen Code.

**Q: Wie führe ich Tests aus?**  
A: Abhängig vom Projekt - meist `npm test`, `pytest`, etc.

## 🏖️ Urlaub & Abwesenheit

**Q: Wie beantrage ich Urlaub?**  
A: Siehe [Urlaubsantrag](Urlaubsantrag) für den vollständigen Prozess.

**Q: Wie viel Urlaub steht mir zu?**  
A: 30 Tage pro Jahr.

**Q: Wie früh muss ich Urlaub beantragen?**  
A: Mindestens 2 Wochen vorher. Bei kurzfristigem Bedarf direkt mit Vorgesetztem sprechen.

**Q: Was passiert mit Resturlaub?**  
A: Verfällt zum 31.03. des Folgejahres.

**Q: Wie melde ich mich krank?**  
A: Am ersten Tag telefonisch beim Vorgesetzten. Ab 3. Tag: Arbeitsunfähigkeitsbescheinigung.

**Q: Wie erfasse ich meine Arbeitszeit?**  
A: Siehe [Zeiterfassung](Zeiterfassung). Arbeitsbeginn, -ende und Pausen dokumentieren.

**Q: Wie viele Home Office Tage sind erlaubt?**  
A: 2 Tage pro Woche, im Team-Kalender eintragen.

A: 10:00 - 15:00 Uhr (teamabhängig, bitte im Team erfragen).

## 💰 Finanzen

**Q: Wie reiche ich Spesen ein?**  
A: Siehe [Company Processes](Company-Processes) → Spesen und Reisekosten.
